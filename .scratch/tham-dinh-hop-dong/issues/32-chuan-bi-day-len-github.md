# 32 - Chuẩn bị đưa project lên GitHub

Status: needs-info
Blocked by: 31

## Vấn đề

Người dùng muốn đưa project lên GitHub cho sếp xem (2026-11-11). `.scratch/` và `docs/` được theo dõi trong git và có đoạn trích lấy từ Hợp đồng TOSS (số hotline, email, lý do của model, ghi chú Bộ chuẩn); đưa lên GitHub là gửi ra dịch vụ ngoài, ADR 0001 cần phê duyệt của công ty. Agent không giúp che việc dùng AI (xóa `Co-Authored-By`, viết lại lịch sử).

## Đề xuất (Q215, hỏi lại sau issue 31)

- Rà `.scratch/`, `docs/`, thông điệp commit để tìm nội dung lấy từ Hợp đồng, đề xuất cắt hoặc che trước khi đưa lên repo private.
- Viết đoạn mô tả cho sếp: cách dùng AI (Claude Code viết code và test, Qwen on-prem thẩm định), dữ liệu đi đâu, cách kiểm soát chất lượng.
- Đưa lên sau khi người dùng đã hỏi sếp hoặc công ty.
